# Customer Survey Form

## Giới thiệu

Dự án thực hành xây dựng biểu mẫu khảo sát khách hàng (Customer Survey Form) bằng HTML, dựa trên giao diện mẫu được cung cấp trong bài tập CodeGym.

## Mục tiêu

- Nắm vững cấu trúc và cách sử dụng các thành phần HTML Form.
- Biết cách sử dụng các loại input phù hợp.
- Xây dựng biểu mẫu có cấu trúc rõ ràng, dễ sử dụng.
- Thực hành quản lý mã nguồn với Git và GitHub.

## Yêu cầu chức năng

- Hiển thị biểu mẫu khảo sát khách hàng theo giao diện mẫu.
- Cho phép người dùng nhập thông tin và lựa chọn câu trả lời.
- Sử dụng các thành phần form như input, label, select, textarea và button theo nhu cầu.
- Cho phép người dùng gửi biểu mẫu bằng nút Submit.

## Công nghệ sử dụng

- HTML5
- CSS3 (nếu cần tùy chỉnh giao diện)
- Git và GitHub

## Cấu trúc dự án

```text
customer-survey-form/
├── index.html
├── README.md
└── .gitignore
```

## Cách chạy dự án

1. Clone repository về máy.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` bằng trình duyệt hoặc Live Server.
